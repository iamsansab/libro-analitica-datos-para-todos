# ANALÍTICA DE DATOS PARA TODOS: De la información al conocimiento para la toma de decisiones estratégicas
**Repositorio Oficial y Material Complementario**

Bienvenido al repositorio oficial del libro académico *"ANALÍTICA DE DATOS PARA TODOS: De la información al conocimiento para la toma de decisiones estratégicas"*. Este espacio ha sido creado para garantizar la reproducibilidad técnica del caso de estudio aplicado sobre la contratación pública en Colombia (SECOP II - Departamento del Quindío).

## 📂 Contenido del Repositorio

En este repositorio encontrará los siguientes insumos técnicos:

1. **`Script_Maestro.R`**: Código fuente en lenguaje R estructurado para la conexión a la API de Socrata (datos.gov.co), limpieza de *outliers*, normalización de fechas y cálculo de desviaciones monetarias.
2. **Carpeta `/datos_procesados/`**: Contiene los archivos `.csv` listos para ser importados a cualquier motor de Inteligencia de Negocios (Tablas de Hechos y Dimensiones).
3. **`Dashboard_Ejecutivo.pbix`**: Archivo editable de Microsoft Power BI Desktop que contiene el modelo relacional en estrella (*Star Schema*), la dimensión calendario, las medidas en DAX y el diseño visual interactivo.

## 🚀 Cómo utilizar este material
* Para ejecutar el código en R, se recomienda utilizar el entorno **RStudio**.
* Para visualizar y modificar el tablero de control, debe descargar e instalar gratuitamente **Microsoft Power BI Desktop**.
* Los archivos están diseñados para fines académicos y de auditoría. Se invita a estudiantes y profesionales a descargar el modelo (botón verde `Code` > `Download ZIP`) y adaptarlo a otras entidades territoriales del país.
